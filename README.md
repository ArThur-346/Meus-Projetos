Sistema de Usuários em Java
Projeto desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos (POO).

Funcionalidades
Cadastro de clientes
Cadastro de administradores
Exibição das informações dos usuários
Utilização de herança entre classes
Conceitos Aplicados
Classes Abstratas
Herança
Polimorfismo
Encapsulamento
Construtores
Sobrescrita de Métodos (Override)
Estrutura
Usuario
Classe abstrata que contém informações comuns aos usuários.

Cliente
Herda de Usuario e possui atributos relacionados ao cliente.

Adm
Herda de Usuario e possui atributos relacionados ao administrador.

Exemplo de Saída
cliente: Arthur id: 12345 idade: 20 saldo: 100000.0
administrador: Arthur id: 54321 idade: 19 per missao: contabi
Tecnologias Utilizadas
Java
Eclipse IDE
Objetivo
Praticar os principais conceitos de Programação Orientada a Objetos utilizando Java.
